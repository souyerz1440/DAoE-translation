# 7.2 对有重复的 $2^{k}$ 因子设计作区组化

假设 $2^{k}$ 因子设计重复了 $n$ 次。这与第 5 章讨论的情形相同，在那里我们说明了如何把一般因子试验安排在区组中。如果有 $n$ 次重复，那么每一组非齐性条件就定义一个区组，而每次重复都在其中一个区组内进行。每个区组（或每次重复）内的试验按随机顺序进行。该设计的分析与任何区组化因子试验类似；例如见 5.6 节的讨论。

## 例 7.1

考虑 6.2 节首次描述的化学过程试验。假设单批原材料只能做四次试验。因此，要完成该设计的全部三次重复，需要三批原材料。表 7.1 给出该设计，其中每批原材料对应一个区组。

**表 7.1 安排在三批原材料（区组）中的化学过程试验**

| | 区组 1 | 区组 2 | 区组 3 |
| --- | --- | --- | --- |
| | (1) = 28 | (1) = 25 | (1) = 27 |
| | $a$ = 36 | $a$ = 32 | $a$ = 32 |
| | $b$ = 18 | $b$ = 19 | $b$ = 23 |
| | $ab$ = 31 | $ab$ = 30 | $ab$ = 29 |
| 区组合计： | $B_1$ = 113 | $B_2$ = 106 | $B_3$ = 111 |

区组的平方和由区组合计计算。设 $B_{1}$、$B_{2}$ 和 $B_{3}$ 表示区组合计（见表 7.1），则

$$
\begin{array}{r l} SS_{\text{Blocks}} & = \sum_{i = 1}^{3} \frac{B_{i}^{2}}{4} - \frac{y_{...}^{2}}{12} \\ & = \frac{(113)^{2} + (106)^{2} + (111)^{2}}{4} - \frac{(330)^{2}}{12} \\ & = 6.50 \end{array}
$$

三个区组之间有两个自由度。表 7.2 表明：如果该设计在区组中运行，所得结论与 6.2 节的结论完全相同，而且区组效应相对较小。区组的 $F$ 统计量为 $F_{0} = (6.50/2)/4.14 = 0.79$，不显著。
