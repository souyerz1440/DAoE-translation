# 习题与答案

本栏目与正文翻译配套，按“**章节 → 题号 → 独立页面**”组织。每道题都有单独的网址，完整展示中文题目背景、各小问、原始数据及答案解析。

习题以 **第 9 版章末 Problems** 为主。正文翻译以第 10 版为基础，两部分的题号不保证相同；本栏目逐题按题意匹配你提供的答案文件，避免仅靠题号对应。

## 阅读方法

- **题号**：始终使用第 9 版编号。每题旁的参考说明标明答案文件中的题号，带 S 的题目及保留题保留原标识。
- **题目与数据**：独立页面保留题目的背景、各项任务、数值、单位与假设，小问逐项列出；配对题按检验员、双胞胎对或梁逐行呈现。续题提供关联题链接，涉及原数据时在本页重列，便于独立阅读。
- **答案与解析**：在题目下方直接展示方法、公式、数值与解释。开放题的具体方案为参考示例，无唯一标准答案。
- **逐题浏览**：左侧按章列出题号；每题底部可前往上一题、下一题或本章目录。独立页面的网址可直接分享或收藏。
- **图表与精度**：重新绘制的图表使用中文标签；数值一般显示 6 位有效数字。原资料四舍五入或不同近似方法可能造成末位差异。极小的 P 值写成科学计数法，避免误解成恰好为零。
- **回到正文**：各章习题页顶部提供正文链接；正文第 1～3 章的章首页也设有习题入口。

这些答案并非每题都有完整推导。答案文件只有提纲、没有对应题或存在明显矛盾时，本页补充了解析，并在题旁说明。补充内容不冒充原答案逐字译文。

以下是影响结论的代表性校订，完整说明位于对应题内：

| 题目 | 处理方式 |
| --- | --- |
| 2.10 | 明确均值差与 t 统计量的符号矛盾，并按第 9 版要求给出 95% 区间 |
| 2.16 | 将误填成检验统计量的“95% 均值下限”改为正确下限 |
| 2.46 | 按第 9 版表 2.1 重新计算水泥砂浆 Welch 区间 |
| 2.50 | 区分已知总体方差的 Z 规划与未知方差的 t 规划 |
| 2.53～2.54 | 按“总体标准差已知”的前提使用 Z 检验与正态区间 |
| 3.3～3.4 | 更正错误的 P 值范围，3.4 在 0.05 水平不显著 |
| 3.40～3.41 | 按实际重复次数计算组内相关系数区间 |
| 3.50 | 说明题目“小时”与原电池寿命数据“周”的单位矛盾 |
| 3.52～3.53 | 根据题目明确给出的四个均值计算非中心 F 功效，不混用最不利均值配置 |

所有统计推断均以题目给定的抽样、随机化、正态性及方差结构为前提。尤其注意：**未拒绝相等，不等于证明相等；统计显著，也不等于具有实际意义。**
