# 习题 1.7：汽车燃油经济性

[习题与答案](../../index.md) / [第 1 章　引言](../chapter01.md)

第 9 版 · 第 1 章 · 原书章末习题见印刷页 21～22。

## 题目

几乎人人都关心汽油价格。请构造一幅因果图，识别可能影响你的汽车单位燃油行驶里程的因素。你会如何实施试验，判断这些因素是否确实影响燃油经济性？

## 答案与解析

可把因果图按以下分支组织，汇入“单位燃油行驶里程”这一结果。

| 主分支 | 潜在因素 |
| --- | --- |
| 车辆 | 车重、发动机状态、轮胎及胎压、保养情况 |
| 驾驶 | 平均车速、急加速、急刹车、怠速时间 |
| 环境与道路 | 坡度、路况、交通拥堵、气温、风速 |
| 燃油与附件 | 燃油类型、空调负载、车载附件 |
| 测量 | 加油量测量误差、里程表误差、起止状态 |

可在封闭场地或规定工况下研究两个合规胎压水平和两个速度水平，固定车辆与载荷，按日期区组化，随机安排处理顺序并独立重复。仅收集日常驾驶记录通常难以排除拥堵、天气等混杂；因果图本身也不能证明因果关系。
