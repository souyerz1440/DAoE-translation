# 习题 3.13：混合方法的均值与均值差区间

[习题与答案](../../index.md) / [第 3 章　单因子试验与方差分析](../chapter03.md)

第 9 版 · 第 3 章 · 原书章末习题见印刷页 125～134。

## 题目

重新考虑习题 [3.11](./exercise-3-11.md) 中的水泥混合方法试验。分别求每一种混合方法所生产水泥的总体平均抗拉强度的 95% 置信区间；再求混合方法 1 与 3 的总体均值之差的 95% 置信区间。这些区间是否有助于解释试验结果？

**所用数据（来自习题 [3.11](./exercise-3-11.md)）**

| 组别／处理条件 | 观测值（同一行属于同一组） |
| --- | --- |
| 1 | 3129，3000，2865，2890 |
| 2 | 3200，3300，2975，3150 |
| 3 | 2800，2900，2985，3050 |
| 4 | 2600，2700，2600，2765 |

## 答案与解析

用 $\bar y_i\pm t_{0.975,12}\sqrt{MS_E/4}$：

| 组别 | 95% 均值置信区间（逐个区间） |
| --- | --- |
| 1 | (2847.62, 3094.38) |
| 2 | (3032.87, 3279.63) |
| 3 | (2810.37, 3057.13) |
| 4 | (2542.87, 2789.63) |

方法 1 减方法 3 的均值差为 37.25，区间约 **$(−137.23,211.73)$ lb/in²**，包含零，不能认定两方法均值不同。单个均值区间是否重叠不能直接替代均值差检验。
