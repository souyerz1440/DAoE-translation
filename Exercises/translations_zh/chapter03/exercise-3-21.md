# 习题 3.21：不等样本量的 Tukey 比较

[习题与答案](../../index.md) / [第 3 章　单因子试验与方差分析](../chapter03.md)

第 9 版 · 第 3 章 · 原书章末习题见印刷页 125～134。

## 题目

用 Tukey 方法重做习题 [3.20](./exercise-3-20.md) 第（d）问中的处理均值比较。你能得出什么结论？请仔细说明，为适应各组样本量不相等，应怎样修改比较方法。

**所用数据（来自习题 [3.20](./exercise-3-20.md)）**

| 组别／处理条件 | 观测值（同一行属于同一组） |
| --- | --- |
| 100 | 21.8，21.9，21.7，21.6，21.7 |
| 125 | 21.7，21.4，21.5，21.4 |
| 150 | 21.9，21.8，21.8，21.6，21.5 |
| 175 | 21.9，21.7，21.8，21.4 |

## 答案与解析

使用 Tukey–Kramer 方法，比较 $i,j$ 的区间半宽为

$$q_{0.95,a,N-a}\sqrt{\frac{MS_E}{2}\left(\frac1{n_i}+\frac1{n_j}\right)}.$$

| 均值对 | 均值差 | 95% 区间 | 显著 |
| --- | --- | --- | --- |
| 1 − 2 | 0.24 | (-0.0726611, 0.552661) | 否 |
| 1 − 3 | 0.02 | (-0.27478, 0.31478) | 否 |
| 1 − 4 | 0.04 | (-0.272661, 0.352661) | 否 |
| 2 − 3 | -0.22 | (-0.532661, 0.0926611) | 否 |
| 2 − 4 | -0.2 | (-0.529574, 0.129574) | 否 |
| 3 − 4 | 0.02 | (-0.292661, 0.332661) | 否 |

全部比较均不显著。不能简单把所有组样本量替换成某个整数平均值；各均值对有不同标准误。
