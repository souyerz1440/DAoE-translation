# 习题 3.3：五水平完全随机设计

[习题与答案](../../index.md) / [第 3 章　单因子试验与方差分析](../chapter03.md)

第 9 版 · 第 3 章 · 原书章末习题见印刷页 125～134。

## 题目

一位试验者实施了一个单因子完全随机设计，该因子有 5 个水平，每水平 3 次重复。计算得到的 F 统计量为 4.87。请给出 $P$ 值的上下界。

## 答案与解析

自由度 $(4,10)$，$P=\mathbf{0.019330}$，故 $0.01<P<0.025$。原答案把两端不等号顺序写反，此处更正。
