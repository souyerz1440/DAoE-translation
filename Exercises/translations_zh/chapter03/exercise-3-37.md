# 习题 3.37：位置变异的占比与降低空间

[习题与答案](../../index.md) / [第 3 章　单因子试验与方差分析](../chapter03.md)

第 9 版 · 第 3 章 · 原书章末习题见印刷页 125～134。

## 题目

考虑习题 [3.36](./exercise-3-36.md) 描述的气相沉积试验。

**所用数据（来自习题 [3.36](./exercise-3-36.md)）**

| 组别／处理条件 | 观测值（同一行属于同一组） |
| --- | --- |
| 1 | 2.76，5.67，4.49 |
| 2 | 1.43，1.7，2.19 |
| 3 | 2.34，1.97，1.47 |
| 4 | 0.94，1.36，1.65 |

**（a）** 估计均匀性响应的总变异。


**（b）** 总变异中有多少来自反应器位置之间的差异？


**（c）** 如果能消除反应器的位置间变异，均匀性响应的变异可降低到什么水平？你认为这是否是一个重要的降低？

## 答案与解析

$n_0=3$，矩估计为 $\hat\sigma^2=0.652183$，$\hat\sigma_\tau^2=1.58481$。总方差为 2.23699，组间方差占比为 70.85%。组内相关系数的 95% 置信区间（截断到参数空间）为 $(0.150301, 0.975517)$。误差方差的精确 95% 卡方区间为 $(0.297554, 2.39363)$。

消除位置间变异后，理论方差剩下 $\hat\sigma^2$，即当前总方差约 **29.15%**，降低约 **70.85%**。这是潜在工程改进空间，是否有实际价值应结合成本与均匀性目标；不能把区间较宽直接解释为“降低不重要”。原答案在相关区间代入中用错每位置重复次数，本页按每组 3 次处理。
