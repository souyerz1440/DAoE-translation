# 习题 3.51：均值差区间精度与电池样本量

[习题与答案](../../index.md) / [第 3 章　单因子试验与方差分析](../chapter03.md)

第 9 版 · 第 3 章 · 原书章末习题见印刷页 125～134。

## 题目

考虑习题 [3.30](./exercise-3-30.md) 的电池试验。如果希望构造两个品牌平均寿命之差的 95% 置信区间，且精度达到 ±2 周，每个品牌必须测试多少节电池？

**所用数据（来自习题 [3.30](./exercise-3-30.md)）**

| 组别／处理条件 | 观测值（同一行属于同一组） |
| --- | --- |
| 1 | 100，96，92，96，92 |
| 2 | 76，80，75，84，82 |
| 3 | 108，100，96，98，100 |

## 答案与解析

以 $MS_E=15.6$ 为规划值，解

$$t_{0.975,3(n-1)}\sqrt{\frac{2(15.6)}n}\le2.$$

逐个整数搜索得 **$n=31$**，总数 93；此时半宽约 1.993。这是指定均值对的区间精度，若要求所有均值对同时覆盖，则应使用多重比较临界值，所需样本量更大。
