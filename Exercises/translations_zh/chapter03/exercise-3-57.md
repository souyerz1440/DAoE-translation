# 习题 3.57：正规方程、约束与可估函数

[习题与答案](../../index.md) / [第 3 章　单因子试验与方差分析](../chapter03.md)

第 9 版 · 第 3 章 · 原书章末习题见印刷页 125～134。

## 题目

考虑习题 [3.26](./exercise-3-26.md) 的三种自动阀门电路响应时间数据。

**所用数据（来自习题 [3.26](./exercise-3-26.md)）**

| 组别／处理条件 | 观测值（同一行属于同一组） |
| --- | --- |
| 1 | 9，12，10，8，15 |
| 2 | 20，21，23，17，30 |
| 3 | 6，5，8，16，7 |

**（a）** 写出最小二乘正规方程，在通常约束 $\sum_{i=1}^3\hat\tau_i=0$ 下求解 $\hat\mu$ 和 $\hat\tau_i$，并估计 $\tau_1-\tau_2$。


**（b）** 改用约束 $\hat\tau_3=0$ 求解第（a）问方程。所得 $\hat\mu$ 和 $\hat\tau_i$ 是否与前面相同？为什么？再次估计 $\tau_1-\tau_2$ 并比较。你能对处理效应对比的估计作出什么判断？


**（c）** 分别用两套方程解估计 $\mu+\tau_1$、$2\tau_1-\tau_2-\tau_3$ 和 $\mu+\tau_1+\tau_2$，比较所得结果。

## 答案与解析

**模型与假设**：$y_{ij}=\mu+\tau_i+\epsilon_{ij}$，$\epsilon_{ij}\overset{\mathrm{iid}}\sim N(0,\sigma^2)$，三电路各 5 次重复。这里求参数与可估函数，不实施新的总体显著性检验。

### （a）和为零约束

正规方程为

$$15\hat\mu+5\hat\tau_1+5\hat\tau_2+5\hat\tau_3=207,$$
$$5\hat\mu+5\hat\tau_1=54,\quad5\hat\mu+5\hat\tau_2=111,\quad5\hat\mu+5\hat\tau_3=42.$$

采用 $\sum_i\hat\tau_i=0$，估计量为 $\hat\mu=\bar y_{\cdot\cdot}$、$\hat\tau_i=\bar y_i-\bar y_{\cdot\cdot}$。结果 $\hat\mu=13.8$、$\hat\tau=(-3,8.4,-5.4)$，$\widehat{\tau_1-\tau_2}=\bar y_1-\bar y_2=-11.4$。

### （b）以电路 3 为基准

取 $\hat\tau_3=0$，估计量为 $\hat\mu=\bar y_3$、$\hat\tau_i=\bar y_i-\bar y_3$。结果 $\hat\mu=8.4$、$\hat\tau=(2.4,13.8,0)$。单个参数数值改变，但 $\widehat{\tau_1-\tau_2}=-11.4$ 不变；可估对比不依赖识别约束。

### （c）三个函数的估计

按给定线性组合将上述参数估计代入：

| 函数 | 和为零约束 | 电路 3 为基准 |
| --- | --- | --- |
| $\mu+\tau_1$ | 10.8 | 10.8 |
| $2\tau_1-\tau_2-\tau_3$ | −9 | −9 |
| $\mu+\tau_1+\tau_2$ | 19.2 | 24.6 |

前两个分别可写为组均值的线性组合，故可估；最后一个在过参数化模型下不是可估函数，不能给出不依赖约束的唯一估计。
