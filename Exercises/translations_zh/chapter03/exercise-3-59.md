# 习题 3.59：绝缘液的 Kruskal–Wallis 检验

[习题与答案](../../index.md) / [第 3 章　单因子试验与方差分析](../chapter03.md)

## 题目

对 [3.27](./exercise-3-27.md) 做 Kruskal–Wallis 检验，并与通常 ANOVA 比较。

**所用数据（来自习题 [3.27](./exercise-3-27.md)）**

| 组别／处理条件 | 观测值（同一行属于同一组） |
| --- | --- |
| 1 | 17.6，18.9，16.3，17.4，20.1，21.6 |
| 2 | 16.9，15.3，18.6，17.1，19.5，20.3 |
| 3 | 21.4，23.6，19.4，18.5，20.5，22.3 |
| 4 | 19.3，21.1，16.9，17.5，18.3，19.8 |

## 答案与解析

对所有寿命合并排序，同值使用平均秩，计算秩和统计量并作同秩修正。得 **$H=6.21770$**，以 $\chi^2_3$ 近似，$P=\mathbf{0.10149}$。在 0.05 水平未拒绝，与 ANOVA 的不显著结论一致。

Kruskal–Wallis 一般比较分布；只有在分布形状相近等条件下，才可解释为位置或中位数差异，不是无需任何假定的均值检验。
