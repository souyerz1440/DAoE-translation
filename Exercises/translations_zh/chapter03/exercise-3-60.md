# 习题 3.60：电路噪声的 Kruskal–Wallis 检验

[习题与答案](../../index.md) / [第 3 章　单因子试验与方差分析](../chapter03.md)

## 题目

对 [3.28](./exercise-3-28.md) 做 Kruskal–Wallis 检验，与通常 ANOVA 比较。

**所用数据（来自习题 [3.28](./exercise-3-28.md)）**

| 组别／处理条件 | 观测值（同一行属于同一组） |
| --- | --- |
| 1 | 19，20，19，30，8 |
| 2 | 80，61，73，56，80 |
| 3 | 47，26，25，35，50 |
| 4 | 95，46，83，78，97 |

## 答案与解析

同秩修正后 **$H=14.93102$**，参考 $\chi^2_3$，$P=\mathbf{0.001877}$，拒绝各组分布相同，与 ANOVA 的显著结论一致。原答案重复使用“3.52”编号，本题对应其没有 S 后缀的第二个 3.52；这里保留第 9 版的 3.60。
