## 本地预览

电子书用 Jupyter Book 2 和 MyST `book-theme` 构建（与 `slp3翻译计划` 相同）。直接运行根目录的 `start.bat`：
首次会创建 `.venv-book` 虚拟环境、安装 `requirements-book.txt` 依赖，然后启动 <http://localhost:3000/>
并自动打开浏览器；`Ctrl+C` 停止。

```powershell
# 手工等效命令
python -m venv .venv-book
.\.venv-book\Scripts\python.exe -m pip install -r requirements-book.txt
.\.venv-book\Scripts\jupyter.exe book start

# 只构建静态站点（产物在 _build/html，不启服务器）
.\.venv-book\Scripts\jupyter.exe book build --html
```

新增整章译文后需同步更新四处：`toc.yml`、`myst.yml` 里 `project.exclude` 的排除项、`book/progress.md`
与 `book/index.md` 的“已上线章节”。
