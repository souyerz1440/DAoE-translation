# 第 1 章习题与答案：引言

## 1.1 爆米花中未爆开玉米粒的比例

**题目**：设计一个试验，研究爆米花中未爆开玉米粒的比例。完成第 1.4 节试验设计指南的前 3 步。是否存在难以控制的重要变异来源？

:::{admonition} 答案与解析
:class: dropdown

1. **明确问题**：寻找使未爆开比例尽可能低的加工条件，同时避免焦糊。仅增加加热时间可能降低未爆开比例，却损害成品质量，因此可增加焦糊比例作为约束。
2. **选择响应**：用“未爆开粒数 ÷ 初始总粒数”度量，每次使用相同数量的玉米粒。也可按质量定义比例，但应事先统一口径，避免加热失水影响分母。
3. **选择因子、水平和范围**：可考察玉米品牌（两个品牌）、储存时间（新鲜、较久）、加热方式（炉灶、微波炉）、加热时间和用油量。时间、温度等水平应通过预试验确定安全、可行的范围。

难以完全控制的变异包括玉米粒内部含水量、粒径、原料批次、加热设备内部温度分布等。可用同批原料、固定装料量、按批次区组化以及随机化运行顺序减轻影响。原答案给出的温度和时间只是举例，不应直接视为通用操作条件。
:::

## 1.2 米饭烹煮试验

**题目**：假设你希望研究哪些因素可能影响米饭的烹煮结果。

（a）在这个试验中，你会用什么作为响应变量？如何测量这个响应？
（b）列出所有可能影响响应的潜在变异来源。
（c）完成第 1.4 节试验设计指南的前 3 步：认识并陈述问题、选择响应变量、选择因子及其水平和范围。

:::{admonition} 答案与解析
:class: dropdown

（a）可用口感评分、硬度、含水量或烹煮时间作为响应。口感评分应由不知道处理条件的评价者按统一量表评定；硬度可用质构仪测量。预先指定主要响应，避免事后只报告最有利的一项。

（b）可能的来源有米的品种与批次、储存时间、初始含水量、米水比、浸泡时间、加热程序、锅具、保温时间及评价者。

（c）示例问题为“在可接受的烹煮时间内提高米饭口感评分”。响应设为统一量表的盲评平均分；研究因子可选米水比（1:1.2、1:1.5）、浸泡时间（0、30 分钟）及烹煮程序（普通、精煮）。固定米的批次和每锅用量，每锅作为独立试验单位；不同评价者对同一锅的打分不能算作多锅独立重复。
:::

## 1.3 花卉生长试验

**题目**：假设你希望比较庭院花卉在不同日照、浇水、施肥及土壤条件下的生长情况。请完成第 1.4 节试验设计指南的前 3 步。

:::{admonition} 答案与解析
:class: dropdown

明确问题：确定能促进指定品种花卉生长的栽培条件。选择响应：例如 6 周内株高增量、干生物量或开花数；提前规定测量时间和方法。选择因子：日照时长、每日浇水量、肥料浓度、土壤类型，每个因子先选两个可行水平。

使用生长状况相近的植株，随机分配到处理；以位置或初始大小作区组。一个盆内多株植物可能共享水肥条件，应明确盆还是植株才是独立试验单位。因子间可能有交互作用，例如施肥效果可能依赖浇水量，适合采用因子设计。
:::

## 1.4 自选试验

**题目**：选择一个感兴趣的试验，完成试验设计指南的前 3 步。

:::{admonition} 答案与解析
:class: dropdown

示例：研究纸飞机的飞行距离。

1. 问题：在固定投掷方式下，寻找平均飞行距离较长且稳定的折叠方案。
2. 响应：从投掷线到首次落地点的水平距离，单位为米；同时记录偏离直线的距离。
3. 因子与水平：纸张定量（70、90 g/m²）、翼宽（窄、宽）、机头配重（无、有）。固定纸张尺寸、投掷者和室内环境，随机安排运行顺序。

重新制作一架纸飞机属于独立制作重复；同一架连续投掷多次主要反映投掷变异，应在分析中保留飞机身份。
:::

## 1.5 Fisher 与洛桑试验站

**题目**：查找 Ronald A. Fisher 爵士及其在洛桑农业试验站（Rothamsted）从事农业试验设计工作的资料。

:::{admonition} 答案与解析
:class: dropdown

参考综述：Fisher 将统计推断与农业田间试验紧密结合，系统发展了随机化、重复和局部控制的试验设计原则，以及分析试验数据的方差分析方法。田间土壤肥力存在空间差异，区组设计能将这类可识别的变异与处理效应区分开；随机化为有效的误差评估和统计检验提供依据。

可围绕他在洛桑的工作、《Statistical Methods for Research Workers》与《The Design of Experiments》整理阅读报告。原答案未给出完整报告；以上为编者补充的概述，不代表本次进行了实时网页检索。
:::

## 1.6 改进商业网站

**题目**：找一个你感兴趣的企业网站。列出一组可以纳入试验设计的因子，以改进该网站的效果。

:::{admonition} 答案与解析
:class: dropdown

以在线书店为例，可研究搜索框位置、商品主图、价格展示方式、优惠文案、推荐区布局、购买按钮颜色和结算步骤。响应可选购买转化率、每次访问收入或完成结算比例，而不宜仅用页面停留时长替代商业目标。

随机分配访问者到不同版本，并让同一访问者保持相同版本；同时运行各组以降低星期、促销和流量来源的干扰。对多个页面元素做因子试验，可以发现诸如“按钮颜色效果依赖背景颜色”的交互作用。
:::

## 1.7 汽车燃油经济性

**题目**：几乎人人都关心汽油价格。请构造一幅因果图，识别可能影响你的汽车单位燃油行驶里程的因素。你会如何实施试验，判断这些因素是否确实影响燃油经济性？

:::{admonition} 答案与解析
:class: dropdown

可把因果图按以下分支组织，汇入“单位燃油行驶里程”这一结果。

| 主分支 | 潜在因素 |
| --- | --- |
| 车辆 | 车重、发动机状态、轮胎及胎压、保养情况 |
| 驾驶 | 平均车速、急加速、急刹车、怠速时间 |
| 环境与道路 | 坡度、路况、交通拥堵、气温、风速 |
| 燃油与附件 | 燃油类型、空调负载、车载附件 |
| 测量 | 加油量测量误差、里程表误差、起止状态 |

可在封闭场地或规定工况下研究两个合规胎压水平和两个速度水平，固定车辆与载荷，按日期区组化，随机安排处理顺序并独立重复。仅收集日常驾驶记录通常难以排除拥堵、天气等混杂；因果图本身也不能证明因果关系。
:::

## 1.8 独立重复与重复测量

**题目**：什么是重复？为什么试验需要重复？举例说明独立重复与对同一试验单位重复测量的区别。

:::{admonition} 答案与解析
:class: dropdown

独立重复是将同一处理条件施加于独立的试验单位或重新独立执行试验。重复使我们能够估计试验误差，提高处理均值估计的精度，并评估结论的稳定性。

例如，用同一配方独立制备 5 批材料，每批测一次，是 5 次批次重复；对同一批材料连续测 5 次，主要估计测量误差，不能替代 5 个独立批次。后者的观测可能相关，若当成独立重复，会低估标准误。
:::

## 1.9 随机化的重要性

**题目**：为什么随机化在试验中很重要？

:::{admonition} 答案与解析
:class: dropdown

随机分配处理和随机安排运行顺序，能避免处理与时间漂移、设备状态、操作者等外部因素系统关联，降低偏倚，并为统计推断提供依据。它有助于让未知干扰因素的影响分散到各处理，而不是集中于某一组。

随机化不能保证一次有限试验中所有组完全相同，也不能自动消除同一对象的重复测量相关性；仍应检查设计和误差结构。
:::

## 1.10 一次大试验还是序贯试验

**题目**：与序贯开展试验相比，一次性实施规模大、面面俱到的试验有哪些潜在风险？

:::{admonition} 答案与解析
:class: dropdown

试验开始时往往尚不清楚重要因子、合理水平、甚至最合适的响应。一次投入全部资源，可能把很多运行花在无效范围内，也难以及时吸收前期发现。若设备或操作出错，返工成本也更高。

序贯策略可以先筛选因子，再探索重要区域，最后做确认试验。其优势在于利用已获得的信息调整后续设计；但每一阶段仍需预先明确目标、记录调整依据，避免随意反复检验带来的错误率膨胀。
:::

## 1.11 信用卡营销试验

**题目**：你是否收到过邮寄的信用卡申请邀约？邀约中包含哪些“因素”，例如优惠期利率？你认为信用卡公司是否正在通过试验研究哪些因素能使邀约获得最高的积极响应率？请指出这类试验中可能包含的因子。

:::{admonition} 答案与解析
:class: dropdown

潜在因子有优惠期利率、优惠期限、长期利率、信用额度、年费、余额转移条件、积分奖励、礼品及文案形式。可随机向条件相近的客户发送不同邀约，比较申请率或激活率，并记录后续使用情况。

原答案主要列举利率、额度、旧卡余额偿还安排、免息期和奖励积分。是否真的开展试验不能仅凭收到一封邀约判断；客户群差异也可能造成表面上的响应率差异。
:::

## 1.12 电商网站点击试验

**题目**：电商公司可以在网页试验中研究哪些因素，以吸引更多访问者点击进入网站？

:::{admonition} 答案与解析
:class: dropdown

可研究字体大小、字体类型、图像或图标、配色、留白、动画、声音和加载速度，也可加入标题、价格信息及行动按钮的位置。响应应明确为“符合条件的展示中发生点击的比例”。

将访问者随机分组，保持展示条件一致；同一用户的多次展示应按预定规则分析。点击率提高后，还要核对购买转化率，避免通过误导性元素获得无效点击。
:::
